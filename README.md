# 示波器音乐播放器 (Oscilloscope Music Player)

把音乐变成会发光的矢量图形。左声道 → X，右声道 → Y，在 XY 模式下绘制示波器图案。
专为 **Windows** 优化，探索了系统窗口的边界玩法。

## 两种播放模式

| 模式 | 说明 | 性能 |
|------|------|------|
| **单窗口** | 一个窗口里渲染磷光辉光示波器（带余辉拖影 + 辉光叠加 + FFT 频谱） | 流畅、低占用 |
| **粒子多窗口** | 把示波器拆成几十~几百个无边框小窗口，铺在桌面上随声音实时游动 | 吃性能 |

- 单窗口可选分辨率（600/800/900/1200px）和描线抽稀级别。
- 粒子模式可选 **窗口数量（即分辨率）** 与 **粒子大小**。
- 两种模式均支持自定义磷光颜色、循环播放。

## 双渲染后端（单窗口）

单窗口模式支持在启动器里手动选择渲染后端：

| 后端 | 说明 |
|------|------|
| **自动** | 优先尝试 GPU(OpenGL)，失败时静默回退到 CPU(pygame) |
| **GPU (OpenGL)** | 用 moderngl 渲染，FBO 乒乓交换实现余辉，帧率最高；失败则报错返回启动器 |
| **CPU (pygame)** | 纯 pygame Surface 混合渲染，无需 moderngl，兼容性最强 |

## 调试模式（实时调参）

勾选「调试模式」后，播放时会在窗口右侧弹出一个置顶的调试面板，可实时拖动滑块调节渲染参数，**改动即时生效**：

- **余辉衰减 decay** —— 拖尾保留时长，越大拖尾越久。
- **余辉硬地板 floor** —— 把残余的微弱辉光直接截零，防止快速闪动累积导致糊屏。
- **速度→亮度参考 ref** —— 越大整体越亮。
- **最低亮度 min** —— 高速段不至于完全变黑的下限。
- **光束亮度倍率 gain** —— 总亮度开关。
- **叠加方式** —— `add` 经典加色（辉光感强、易过曝）/ `max` 取最大值（永不饱和，专治糊屏）。
- **显示开关** —— 实时切换频谱 / 帧率显示。

> 遇到某些音乐快速闪动导致画面糊掉时，把 decay 调到 0.75 左右，或切换到 `max` 叠加方式即可。

## 安全停止
- 全局热键 **Ctrl+Alt+Q**：任意时刻一键安全停止退出（即使粒子铺满屏幕挡住鼠标）。
- 单窗口与粒子模式均额外支持 **ESC**（返回启动器）。

## 安装与运行
```powershell
pip install -r requirements.txt
python main.py
```
在弹出的启动器里选择音乐文件、模式与参数，点击「开始播放」。

> 推荐 WAV / FLAC / OGG。MP3 需要 libsndfile 支持（较新版本的 soundfile 已内置）。
> 真正的"示波器音乐"素材（专门为 XY 显示制作）效果最佳，普通音乐也能出抽象图形。
>
> 仓库未包含音频素材，请自备音频文件。可在 [oscilloscopemusic.com](https://oscilloscopemusic.com/) 了解示波器音乐。

## 性能优化要点（粒子模式）
- **窗口池**：一次性建好 N 个窗口全程复用，绝不在循环里反复创建/销毁。
- **批量原子移动**：`BeginDeferWindowPos / DeferWindowPos / EndDeferWindowPos`，一帧内统一重定位所有窗口，消除撕裂与抖动。
- **极简移动标志**：`SWP_NOSIZE|SWP_NOZORDER|SWP_NOACTIVATE|SWP_NOREDRAW`。
- **鼠标穿透**：`WS_EX_TRANSPARENT|WS_EX_NOACTIVATE`，铺满屏也不挡操作。
- **平滑出入场**：统一渐显/渐隐 alpha，而非一次性全冒出/全消失。
- 音频回调里同步写入 XY 缓冲，画面与声音严格同步。

## 文件结构
- `main.py` —— 启动器 GUI（含渲染后端、调试模式开关）+ 整合
- `audio_engine.py` —— 播放 + 实时 XY 示波器缓冲（线程安全环形缓冲）
- `single_window.py` —— 单窗口磷光示波器（GPU/CPU 双后端，支持 params 实时调参）
- `debug_panel.py` —— 调试面板（独立线程 tkinter，共享参数实时调节）
- `particle_windows.py` —— Win32 多窗口粒子引擎
- `hotkey.py` —— 全局安全停止热键
